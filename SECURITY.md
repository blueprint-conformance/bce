# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security reports.

Use either private channel:

1. GitHub's private vulnerability reporting on this repository (Security tab →
   “Report a vulnerability”). This is preferred because it keeps discussion and
   remediation in a restricted advisory.
2. If GitHub reporting is unavailable, email the project steward at
   `mitchell@odin-labs.ai` with a subject beginning `[BCE SECURITY]`.

Do not put credentials, access tokens, private keys, or unnecessary personal data in
ordinary email. Send a minimal description first; the steward will arrange a safer
transfer method if sensitive reproduction material is required.

We aim to acknowledge reports through the same private channel within 7 days.
Please include affected versions, impact, and a minimal reproduction where safe.
We appreciate coordinated disclosure and will credit reporters unless anonymity
is requested.

This policy applies to the released v0.1.x line and to `main`.
