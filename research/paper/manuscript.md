## Abstract

BCE is an open-source prototype for converting repository architecture policy into deterministic,
fail-closed checks exposed to humans, CI, and coding agents. We describe the system and a
preregistered evaluation design. We do not yet claim that BCE improves agent outcomes.

## Methods

The benchmark and controlled-study designs are defined by the JSON preregistrations in the parent
directory. Claim-bearing manifests remain unpopulated and unsealed. Product fixtures and the
accelerated instrumentation pilot are development data and are excluded from performance
estimation. Two independent annotators must identify each ground-truth location. Unsupported cases
and collateral violations are reported explicitly.

## Results

Not run. No numerical performance or causal claims are established.

## Limitations

Current extraction is strongest for TypeScript/JavaScript and selected Python import surfaces.
Static evidence cannot establish runtime behavior unless a provenance-bound observation envelope
is supplied. Hash integrity does not establish artifact origin, independent witnessing, or social
governance. Repository configuration cannot prove that hosting-provider branch protection is active.

## Reproducibility

The package tests, consumer-pack test, evidence-bundle verifier, and development corpus validate
mechanics only. A release of empirical results must include the frozen manifests, corpus digests,
raw judgments, environment lock, analysis output, and a claim-to-evidence matrix.
