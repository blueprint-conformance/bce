# Film library

Explore the context spectrum, the earlier architecture walkthrough and the preserved agent-fleet films. The library distinguishes released-engine illustrations, wider reference architecture and historical demonstrations of a separate agent product.

The new interactive C1–C4 spectrum follows one blueprint through narrowing context, inherited rules, concrete findings, scoped repair, evidence and review. These architectural zoom levels are distinct from BCE's constraint type identifiers.

All films are silent. Native playback controls, timed descriptions for the six architecture/launch films, labelled summaries for the four historical agent films and original MP4 downloads keep the collection usable without animation or WebGL.

The complete catalog is versioned with the repository. A dated media release preserves the original video bytes and preview images; SHA-256 identities make the downloads verifiable. Earlier cuts remain available when a new film becomes the feature.

For currently released behavior, follow the [quickstart](quickstart.md) and [release status](../STATUS.md).
